# CRUD Project

A simple MERN stack CRUD application for managing tasks.

## Features

- Create, read, update, and delete tasks
- Backend API with Express and MongoDB
- Testing API through Postman.

## Installation

1. Clone the repository.
2. Install dependencies in the project folder:
   - `npm install`
3. Create a `.env` file for the MongoDB connection string.
4. Start the development server:
   - `npm start` || `npm run dev" || `node src/index.js`

## Usage

- Open the postman.
- Test the API's for add, edit, and remove tasks.

## Notes

- Ensure MongoDB is running and the connection string in `.env` is correct.
